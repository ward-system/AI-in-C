introduction

AI-in-c is a machine learning framework for the C language. It is still in pre-release and you have to add some things manually like

1. Your own training function

2. Your own cost function

3. Your own forward function

(or you can use the ones I defined in main.c)

but do not worry, in the next release I will add a unified library which will make the job reasy

Neuron structure

A single Neuron contains an array of weights and a single bias

You have to allocate the neuron before using it. You can use neuron_alloc function for that

To get the output of a single neuron, you multiply the weights with input and add the bias to them. You can use the neuron_forward function for that

For more efficiency, You have to randomize the weights and biases of your neuron. You can use neuron_rand function for that

Layer structure

A single Layer contains an array neurons

You have to allocate the Layer before using it. You can use layer_alloc function for that

To add a neuron to a specific layer you can use layer_add_neuron function

The output of a single layer is an array of all its neuron outputs. You can use the layer_forward function for that
